EasyIntake Creator Portal (local copy)

Option 1: index.html pe double-click karo, browser me khul jayega.
Option 2 (recommended): folder me terminal kholo aur chalao:
  python -m http.server 8000
phir browser me kholo: http://localhost:8000

Note: Google Fonts internet se load hote hain. Offline me fallback fonts dikhenge.
